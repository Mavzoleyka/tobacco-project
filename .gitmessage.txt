# type(scope): краткое описание изменений
#
# Возможные type:
#   feat     — новая функциональность
#   fix      — исправление бага
#   refactor — улучшение кода без изменения логики
#   style    — только изменения форматирования
#   docs     — документация
#   test     — тесты
#   chore    — обслуживание проекта, обновление зависимостей
#   perf     — оптимизация
#
# Примеры:
#   feat(notifications): add unread counter logic
#   fix(reservations): status transition validation
#
# -----------------------------
# Тело коммита (опционально)
# Расскажи подробнее:
# - что сделал
# - почему сделал
# - важные детали
#
# -----------------------------
# Footer (опционально)
# Например:
#   BREAKING CHANGE: изменена структура таблиц
#   Closes #123
